# File di transito per Instagram

Repository pubblico di servizio del progetto privato `feed-telegram`.
Instagram deve poter scaricare foto e video da un indirizzo pubblico: il progetto usa GitHub Pages per rendere disponibili i file durante la pubblicazione, poi li rimuove dall’albero corrente.

**La rimozione non cancella i file dalla cronologia Git**, né garantisce la cancellazione immediata dalle cache. Non caricare segreti, dati personali riservati o contenuti che non possono restare pubblici. Il repository non è un archivio temporaneo con cancellazione garantita.

Le istruzioni operative e il codice stanno nel repository privato. Evitare modifiche manuali ai file di transito mentre una pubblicazione è in corso.
